# Buzz website — static launch build

Multi-page HTML, CSS and JavaScript website for Vercel. No database, API or backend is included.

## Pages
Home, social experience, Buzz App, Buzz Pro, Marketplace, SunPay, Buzz Safety, Buzz Logistics, Logistics Partners, About, Careers, Early Access, Help & FAQ, Contact, Privacy Notice draft and Terms draft.

## Preview locally
Run `python -m http.server 8000` from this folder and open `http://localhost:8000`.

## Deploy to Vercel
Import this folder/repository into Vercel. Choose Framework Preset **Other**, leave Build Command blank, and set Output Directory to `.`.

## Critical before launch
- Forms are front-end previews only. They validate in the browser but do not send or store submissions. Connect a secure form endpoint/CRM before publishing.
- Confirm every product claim, service feature, supported payment method, escrow term, delivery route, fee and contact detail against the live products.
- The Privacy and Terms pages are draft frameworks and require legal review against actual data practices and applicable Nigerian law before publication.
- Add approved brand logo, imagery, contact details, social links and any required cookie/analytics controls.
- Google Fonts load remotely; self-host fonts if needed.

No WhatsApp references are included.
