# Buzz website

Plain static site. No build step, no server.

Files: index.html, styles.css, app.js, vercel.json

Vercel: Add New > Project > import. Framework Preset: Other. Leave Build Command and Output Directory empty. Root Directory: the folder that contains index.html.

Forms are not connected to anything yet. When you have an endpoint, set ENDPOINT at the top of app.js.
