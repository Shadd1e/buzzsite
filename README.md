# Buzz design kit: start here

Unzip into the root of your Claude Code project, then follow **BUILD-GUIDE.md** from step 2.

| File | What it is |
|---|---|
| `CLAUDE.md` | Instructions Claude Code reads every session |
| `PRODUCT.md` | What Buzz is, audience, voice, truth rules, confirmed logistics rules |
| `DESIGN.md` | Design system + page-by-page specs for the site, logistics, partner portal, admin console and Buzz Web |
| `BUILD-GUIDE.md` | Stack, tools, Impeccable + frontend-design workflow, build order, prompts |
| `reference/homepage-template.png` | The homepage design to match |
| `assets/photos/` | Hand cut-outs (for the slide-in animation), lock illustration, sample avatar. Files marked `PREVIEW-ONLY` are cleaned crops for mockups. Use original photos or chosen stock in the real build. |
| `test-data/` | Fictional fixtures for logistics, admin and Buzz Web. See `test-data/README.md` for IDs that hit every state. |
